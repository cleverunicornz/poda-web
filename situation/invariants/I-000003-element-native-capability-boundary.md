# Element-native capability boundary

## Priority

standard

## Invariant

Poda Web's first migration may change the presentation of capabilities already
implemented by Element Web and Matrix, but it does not add or reinterpret
routes, protocol events, data models, persistent state, network dependencies,
permissions, or user actions.
